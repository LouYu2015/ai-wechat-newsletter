# 发布到微信公众号（house style）

把 Markdown 草稿转成与参考文章
`https://mp.weixin.qq.com/s/umkGnI8FEkFgFKFBm0-pBQ`（群聊周报 Vol.1）
一致的公众号排版，全部内联样式、**无任何超链接**（公众号不支持）。

执行核心是 `scripts/md_to_wechat.py`，样式常量已从参考文章实测提取，不要重新猜测配色。

## 流程

1. **生成 HTML**（先激活项目 venv）：
   ```bash
   source .venv/bin/activate
   python scripts/md_to_wechat.py "data/draft/<稿子>.md"
   ```
   - 输出 `data/draft/<稿子>.wechat.html`（与源文件同目录、同名）。
   - 脚本把 `# H1` 当作**标题**打印到 stderr，不放进正文。

2. **浏览器预览**：用 chrome-devtools MCP 打开 `file://` 绝对路径（中文路径会被 URL 编码，正常），`take_screenshot` 全页截图核对排版。
   - 若公众号编辑页/参考文章还没打开，先 `new_page` 打开 `https://mp.weixin.qq.com/`，等用户登录。

3. **交给用户粘贴**（系统剪贴板的富文本粘贴最稳，默认让用户手动操作，不要试图用浏览器自动粘贴）：
   - 标题 → 复制到公众号「标题」栏。
   - 正文 → 在预览标签页 `⌘A` 全选 → `⌘C` → 编辑器正文区 `⌘V`。
   - 提醒用户粘贴后扫一眼：**@提及药丸的蓝底蓝框、引用框/素材框的底色**是否被编辑器吞掉（`inline-block` 背景偶尔会丢）。

## markdown 约定（脚本据此转换）

| Markdown | 渲染结果 |
|---|---|
| 文档**第一个** `>` 引用块 | 顶部灰色「素材声明」框（内容在脚本里硬编码，含 GitHub 纯文本 URL）|
| 其余 `>` 引用块 | 浅蓝引用框（蓝字 `#2f5b9e`）|
| `` `@昵称` `` | 蓝色 @提及药丸 |
| 其余 `` `code` `` | 行内代码样式 |
| `**加粗**` | `<strong>` |
| `[文字](url)`（正文） | 只保留「文字」，丢弃链接 |
| `[1]` `[5]` 等正文中的数字标记 | 蓝色上标脚注 |
| `## 标题` | 蓝条 H2；含「参考链接」的 H2 之后进入**参考链接模式** |
| `### 标题` | 蓝色 H3 |
| `---` | 浅灰分隔线 |
| 参考链接模式下的段落 | 首行标题（深灰）+ 其余行 URL（灰色小字、可换行）|

## 样式速查（与参考文章一致，改样式时同步改脚本常量）

- 正文：`16px / #3f3f3f / line-height 1.75 / letter-spacing .3px`
- H2：`20px 加粗 / #1a1a1a / 左侧 4px 蓝条 #2b6cd6`
- 引用框：底 `#f2f7ff`、边 `#d3e3fb`、字 `#2f5b9e`
- @提及：底 `#eaf2ff`、边 `#cfe0fb`、字 `#2b6cd6`
- 素材声明框：底 `#f6f7f9`、字 `#8a8a8a`

## 注意

- 始终经 `scripts/md_to_wechat.py` 生成，不要手写整篇 HTML。需要新样式时改脚本常量并跑一遍验证。
- 不生成超链接。若源文里有 markdown 链接，正文丢 URL、参考列表把 URL 留作纯文本。
